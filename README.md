# Swiggy Clone (React)

A front-end clone of the Swiggy food-ordering web app (using live api of swiggy) built with React. This project demonstrates common UI patterns for restaurant listing, menus, cart management, and checkout flows — useful as a learning project or starter template for food-delivery frontends.

## Features
- Responsive restaurant listing and filter options
- Restaurant detail and menu pages
- Add/remove items to/from cart
- Simple cart view with total price
- Basic routing with React Router
- Sample state management (Context API / local state)
